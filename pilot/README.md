# Table 1 psychoacoustic candidate pilot

This folder contains 13 candidate variants with 20 independently randomized
samples per variant (260 WAV files total), plus the Connect task CSV and custom
HTML questionnaire. All audio is mono 48-kHz 24-bit PCM and contains no TTS.

Each Connect CSV row presents one sample from every candidate category. The
questionnaire randomizes the first 12 questions within the browser and always
presents the Zwicker-tone item last to avoid contaminating later judgments.

The Zwicker stimulus follows Gockel and Carlyon (2016): 5-s diotic notched
broadband noise (30-16000 Hz), 2818-4227-Hz notch, 20-ms ramps, followed by
5.5 s of silence. Calibrated reproduction at 51 dB SPL is required for a
faithful level replication.
